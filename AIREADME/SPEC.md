# 对外契约草案

当前为设计草案，没有已运行端点、已冻结工具名、JSON schema 或发布兼容承诺。实现时将本文件收敛为真实接口契约。

## 连接与对象

- 连接使用稳定的 connection_id，Jenkins 和 K8s 连接相互独立。
- Jenkins 对象使用连接、Job 完整路径、Queue ID 或 Build number 定位。
- K8s 对象使用连接、API group、version、kind、namespace、name 和实际 UID 等信息定位。
- 单一明确目标可使用使用者默认配置；多目标歧义必须返回候选或明确错误。
- namespace 适用性随资源的 namespaced 或 cluster-scoped 属性变化。
- 目标解析后回传完整位置，写入计划固定实际路由，不能随会话全局 context 漂移。

## 协议与鉴权

支持本地 stdio 和远程 Streamable HTTP。具体启动命令、URL、端口和配置 schema 在首个可运行版本确定。

stdio 由本地客户端启动，使用本地受控配置和凭据。HTTP 默认绑定回环；远程访问采用受控隧道或服务端访问认证，初始远程直连方案使用令牌凭据。真实值由运行环境管理。

平台账号权限负责最终授权上限。工具 annotations 如实标注副作用，不把 annotations 当成认证或权限执行机制。

## 写操作与确认

默认沿用客户端审批和当前请求的明确范围，MCP 不再强制用户复制一轮确认口令。连接可单独启用额外的预览确认策略。

所有写操作具备生成精确计划的能力，计划包含目标、实际参数、差异、相关原始版本和预期副作用。执行只消费固定计划；额外确认、计划有效期与重复执行保护由统一机制处理。

客户端审批属于宿主交互。普通工具参数中的 actor_id、confirmation_text 或 plan_id 不能独自证明可信用户身份；HTTP 访问身份需来自服务端认证。

Secret 读取与 exec 的能力、输出敏感性和副作用应在工具描述及策略中清楚表达，不能依靠命令名称把 exec 一概标成只读。

## 结果与长操作

统一结果应包含完整目标、原生资源标识、操作 ID、阶段状态、证据时间、错误及缺口。集合和输出支持分页、游标、长度限制与截断标识。

长操作可续查。分别表达已受理、运行中、已完成、失败、超时等待、部分完成和结果未知；具体状态枚举在实现时冻结。

Jenkins 追踪本次 Queue 和 Build，K8s 追踪本次目标和可验证的更新过程。平台成功、资源收敛和业务验证分别返回。

写入响应丢失时保留结果未知，先核对可归属证据。不能通过自动重试或查询 latest 冒称已完成。

## 敏感信息与审计

操作记录保存必要的目标、动作、状态和证据索引。Secret、凭据和敏感请求内容不写运行日志或长期审计；默认诊断摘要不自动展开敏感原值。

显式敏感读取按平台权限和客户端授权返回所请求内容。敏感变更计划的短期保存、失效和恢复机制需在实现时明确，不能以长期明文持久化换取恢复便利。

## 错误和兼容

错误至少区分连接或认证失败、平台拒绝、对象不存在、目标歧义、能力不支持、版本冲突、等待超时和结果未知，保留适当的平台原始状态。

服务信息返回应用版本、构建或内容标识、协议能力与实际工具清单。版本范围由真实兼容性验证确定，未实现工具不进入可调用清单。
