# 推进方向

## Now

首版完整范围已形成可运行实现，完成本地机制、两种 MCP 协议和独立安装验证。保持实际工具、文档与测试一致，准备在使用者明确授权的 Jenkins、namespace 和测试对象上逐项验收。

真实验收优先核对 Job 类型及插件、Queue/Build 归属、配置回读、K8s 工作负载策略、Secret 与 exec。已确认范围完整保留，不用模拟平台通过替代业务验收。

## Next

根据实际目标补齐经验证的平台与客户端兼容矩阵，验证 HTTP 的真实客户端审批、静态认证及受控远程入口。源码托管之后，包发布与版本 tag 按用户明确要求执行。

围绕真实使用反馈完善首次配置和缺口提示，解决被目标平台证据证实的适配问题。

## Later

扩充经过验证的特殊 Jenkins 参数与插件、更多控制器策略、交互 stdin/TTY 以及需要 OAuth 的客户端兼容。真实操作形成稳定方法后，可补充可选 Skill。
